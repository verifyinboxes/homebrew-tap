# VerifyInboxes Homebrew tap

```sh
brew install verifyinboxes/tap/verifyinboxes
```

installs the [VerifyInboxes command-line tool](https://github.com/verifyinboxes/verifyinboxes-cli) on macOS or Linux;
`brew upgrade verifyinboxes` updates it.

The cask in `Casks/` is written by each release of the tool. Changes made here by hand are overwritten.
